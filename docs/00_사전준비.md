## 1. GitHub 계정 및 Copilot 라이선스

### 1-1. GitHub 계정

이미 있다면 이 단계는 건너뜁니다.

1. <https://github.com/join> 에서 가입
2. 회사 이메일 또는 개인 이메일 사용
3. 2FA(2단계 인증) 활성화 권장 — Settings → Password and authentication → Two-factor authentication

### 1-2. Copilot 라이선스 종류

| 플랜 | 가격 | 대상 | Custom Agents / MCP | GHAS 자동수정 |
| :--- | :--- | :--- | :--- | :--- |
| **Free** | ₩0 | 학생 · OSS 메인테이너 · 개인 (제한적) | ❌ | ❌ |
| **Individual (Pro)** | $10/월 | 개인 개발자 | ✅ | ❌ |
| **Business** | $19/월/user | 팀·조직 | ✅ | ⚠️ 조직 정책에 따라 |
| **Enterprise** | $39/월/user | 대기업 (GHE와 통합) | ✅ | ✅ |

> 💡 **처음 사용자**: [Copilot Free](https://github.com/features/copilot)로도 대부분의 실습이 가능합니다. Ch.3의 MCP·Custom Agents 실습부터 Pro 이상이 필요합니다.

### 1-3. 라이선스 활성화

1. GitHub 로그인 → 우측 상단 프로필 → **Your Copilot**
2. **Start free trial** 또는 **Get Copilot**
3. 결제 정보 입력 (Free는 결제 불필요)
4. 활성화 완료 화면 확인

## 2. VS Code + Copilot 확장

### 2-1. VS Code 설치

- <https://code.visualstudio.com/> 에서 최신 버전 다운로드
- Windows: MSI 인스톨러 실행 (Insider 채널도 무관)
- macOS: `.zip` 다운로드 후 Applications로 이동
- Linux: `.deb` 또는 `.rpm` 설치

### 2-2. Copilot 확장 설치

VS Code 확장 마켓플레이스에서 다음 3개를 설치합니다.

| 확장 | 역할 |
| :--- | :--- |
| **GitHub Copilot** | 코드 자동완성 (Inline suggestions) |
| **GitHub Copilot Chat** | Chat, Edit, Agent 모드 |
| **GitHub Pull Requests** | VS Code에서 PR 리뷰 · 생성 (Ch.4 실습용) |

CLI로 한 번에:

```bash
code --install-extension GitHub.copilot
code --install-extension GitHub.copilot-chat
code --install-extension GitHub.vscode-pull-request-github
```

### 2-3. Copilot 로그인

1. VS Code 하단 상태바의 **Copilot 아이콘** 클릭 → **Sign in to GitHub**
2. 브라우저에서 인증 코드 확인 → **Authorize**
3. VS Code로 돌아와 상태바에 `Copilot` 아이콘이 활성화되면 완료

### 2-4. 정상 동작 확인

새 파일 `test.js` 생성 후 아래를 입력:

```javascript
// Function to reverse a string
function reverseString(
```

Copilot이 회색 텍스트로 함수 본문을 제안하면 성공. `Tab`으로 수락, `Esc`로 무시.

## 3. Git 로컬 설정

### 3-1. Git 설치

```bash
# Windows (Git for Windows)
winget install --id Git.Git -e --source winget

# macOS (Homebrew)
brew install git

# Ubuntu / Debian
sudo apt install git

# 버전 확인 (2.40 이상 권장)
git --version
```

### 3-2. 사용자 정보 설정

```bash
git config --global user.name "홍길동"
git config --global user.email "hong@example.com"
git config --global init.defaultBranch main
git config --global pull.rebase false
```

### 3-3. GitHub 인증

**옵션 A: HTTPS + PAT (간단, 권장)**

1. GitHub → Settings → Developer settings → **Personal access tokens (classic)**
2. **Generate new token** → scope: `repo`, `workflow`, `write:packages`
3. 발급된 토큰을 안전한 곳에 저장 (다시 볼 수 없음)
4. `git push` 시 비밀번호 대신 토큰 입력 → OS 자격증명 관리자에 저장됨

**옵션 B: SSH 키 (여러 머신 · 자동화 시 편리)**

```bash
ssh-keygen -t ed25519 -C "hong@example.com"
# 기본 경로(~/.ssh/id_ed25519) 사용, 패스프레이즈 권장
cat ~/.ssh/id_ed25519.pub
# 출력 내용을 GitHub → Settings → SSH and GPG keys → New SSH key 에 등록
```

## 4. Azure 구독 + Azure CLI

### 4-1. Azure 무료 구독 생성

1. <https://azure.microsoft.com/free> 접속
2. Microsoft 계정 로그인 (없으면 가입)
3. **무료로 시작** → 신용카드 등록 (인증용, 자동 청구 없음)
4. 신규 가입 혜택
   - 30일간 사용 가능한 **$200 크레딧**
   - 12개월 인기 서비스 무료 (App Service B1, Container Registry Basic 등)
   - 55개 이상의 상시 무료 서비스

> ⚠️ 회사 구독을 쓰는 경우: 구독 소유자에게 **Contributor** 또는 **Owner** 권한을 요청하세요. Ch.6~9 실습에 필요합니다.

### 4-2. Azure CLI 설치

```bash
# Windows
winget install -e --id Microsoft.AzureCLI

# macOS
brew install azure-cli

# Ubuntu
curl -sL https://aka.ms/InstallAzureCLIDeb | sudo bash

# 버전 확인 (2.60 이상 권장)
az --version
```

### 4-3. Azure 로그인 및 구독 설정

```bash
# 브라우저가 열리며 로그인
az login

# 구독 목록 확인
az account list --output table

# 사용할 구독 선택 (여러 개인 경우)
az account set --subscription "구독 이름 또는 ID"

# 현재 구독 확인
az account show --output table
```

### 4-4. 실습용 리소스 그룹 생성 (선택)

이 커리큘럼의 모든 실습 리소스를 한 곳에 모아두면 나중에 정리하기 편합니다.

```bash
az group create \
  --name rg-copilot-training \
  --location koreacentral
```

> 💰 **비용 관리 팁**: Ch.6~10 실습이 끝난 후에는 `az group delete --name rg-copilot-training --yes --no-wait`로 리소스 그룹 통째로 삭제하면 $0로 리셋됩니다.

## 8. 자주 겪는 문제

| 증상 | 원인 | 해결 |
| :--- | :--- | :--- |
| VS Code에서 Copilot 아이콘에 슬래시가 표시됨 | 로그인 만료 | `Ctrl+Shift+P` → `GitHub Copilot: Sign In` |
| Copilot 제안이 안 뜸 | 파일 언어 지원 안 됨 or 조직 정책 차단 | 다른 언어 파일에서 확인 · IT 관리자 문의 |
| `az login` 브라우저 오류 | 회사 프록시 · IE 리다이렉트 문제 | `az login --use-device-code` |
| `git push` 시 인증 실패 | PAT 만료 or 스코프 부족 | 새 PAT 발급 시 `repo`, `workflow` 스코프 포함 |
| Windows에서 Docker 시작 실패 | Hyper-V or WSL2 비활성화 | 관리자 PowerShell에서 `wsl --install` |
| Copilot Chat이 응답 없음 | VS Code 버전 오래됨 | VS Code 업데이트 |
